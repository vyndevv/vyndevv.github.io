Overview

This Discord bot was designed to provide a complete server management solution for Discord communities. Built with a modular architecture, it makes adding new commands and features straightforward and maintainable.

The bot uses Discord.js v14 and follows a clean command handler pattern with configuration via environment variables for security.

Features

  • Modular command architecture (easy to extend)
  • Moderation: kick, ban, mute, warn system
  • Utility commands: role management, user info, server stats
  • Auto-role on join & welcome messages
  • FR/EN multi-language support built-in
  • Secure config via .env (token never exposed)
