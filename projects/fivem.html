Overview

This FiveM server project started as a personal challenge: build a complete roleplay server entirely from scratch, without relying on pre-made frameworks. Every script, every resource, and every database interaction was hand-written to ensure full control over the codebase.

The project has been in active development for over 6 months, and continues to grow with new features and improvements regularly.

Features

  • Custom inventory system with drag-and-drop UI
  • Dynamic job & economy system with full SQL persistence
  • Unique vehicle customization scripts
  • Advanced player identity & character management
  • Optimized performance (low server-side tick rate)
  • Full admin panel with moderation tools
