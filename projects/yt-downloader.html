YT Downloader.

Application web Python/Flask qui convertit et télécharge n'importe quelle vidéo YouTube en MP3 haute qualité directement depuis le navigateur. Interface dark minimal, zéro installation nécessaire pour l'utilisateur final.

Overview

Débuté comme un exercice d'apprentissage Python avec une interface CustomTkinter, ce projet a évolué en une véritable application web. L'interface desktop a été entièrement remplacée par un frontend web dark minimal servi par un backend Flask — bien plus accessible et esthétique.

Le serveur récupère d'abord les métadonnées de la vidéo (titre, miniature, durée) pour une prévisualisation, puis convertit l'audio via ffmpeg et l'envoie directement au navigateur en téléchargement — sans créer de dossier local côté utilisateur.

Features

  • Prévisualisation avant téléchargement (titre, chaîne, durée, miniature)
  • Conversion MP3 192 kbps côté serveur via yt-dlp + ffmpeg
  • Le fichier MP3 est téléchargé directement par le navigateur — aucun dossier créé
  • Nettoyage automatique des fichiers temporaires après envoi
  • Nommage intelligent du fichier (caractères spéciaux inclus via RFC 5987)
  • Interface web dark minimal responsive — suit le design system du portfolio
  • Lancement en un clic via start.bat
